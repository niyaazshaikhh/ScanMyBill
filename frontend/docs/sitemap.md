# Automatic Sitemap

Last updated: March 26, 2026

`/sitemap.xml` is generated by `app/sitemap.ts` using `lib/seo/sitemap.ts`.

## How It Updates

- The generator scans `app/**/page.(tsx|ts|jsx|js|mdx)`.
- When a public page file is added, removed, or renamed, the next sitemap generation reflects it.
- `lastModified` is derived from each page file's filesystem modification timestamp.
- `changeFrequency` and `priority` are assigned through route-aware SEO hints.

## What Is Excluded

- Private route groups: `(app)` and `(auth)`.
- Dynamic routes with unresolved params (for example `[slug]`).
- Explicit blocked paths:
  - `/signin`, `/signup`, `/forgot-password`, `/reset-password`, `/admin/signin`
- Prefix-based exclusions:
  - `/admin`, `/api`, `/dashboard`, `/clients`, `/create`, `/invoices`, `/settings`, `/newsletter`, `/hsn-sac-master-list`, `/client-analytics`
- Any route directory containing a `noindex` directive in `head.*`, `page.*`, or `layout.*`.

## Robots Integration

- `app/robots.ts` publishes `Sitemap: https://<your-domain>/sitemap.xml`.
- It also disallows known private paths for crawlers.

## Revalidation

- `app/sitemap.ts` sets `revalidate = 3600` (hourly refresh window).
- In production, route code changes still require the normal deploy cycle.
