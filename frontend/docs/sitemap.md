# Automatic Sitemap

`/sitemap.xml` is generated by `app/sitemap.ts` using `lib/seo/sitemap.ts`.

## How It Updates Automatically

- The generator scans `app/**/page.(tsx|ts|jsx|js|mdx)`.
- When a public page file is added, removed, or renamed, the next sitemap run reflects it automatically.
- `lastmod` is derived from each page file's last modified timestamp.
- `changefreq` and `priority` are assigned by route-aware SEO defaults.

## What Is Excluded

- Private route groups: `(app)` and `(auth)`.
- Auth/admin/internal paths (for example: `/signin`, `/dashboard`, `/admin`, `/invoices`, etc.).
- Dynamic routes with unresolved params (for example: `[slug]`) are skipped.
- Any route directory containing a `noindex` directive in `head.*`, `page.*`, or `layout.*`.

## Robots Integration

- `app/robots.ts` publishes the sitemap URL:
  - `Sitemap: https://<your-domain>/sitemap.xml`
- It also disallows known private paths for crawlers.

## Revalidation

- `app/sitemap.ts` uses `revalidate = 3600` so sitemap output refreshes periodically.
- In production, route code changes still require your normal deploy cycle.
